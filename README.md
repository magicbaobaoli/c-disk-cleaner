# C Disk Cleaner

> DSH 插件（包名仍然是 `dsh-cleaner`）。仓库：https://github.com/magicbaobaoli/c-disk-cleaner

DSH 右上角常驻一枚小垃圾桶按钮，**随时点一下就能清掉可安全重建的缓存、释放 C 盘空间**。

![演示](docs/preview.png)

## 为什么值得装

清缓存这件事本来要去翻三层目录、记哪些能删哪些不能删。装了这个插件，右上角永远有一个按钮：

- **随时可用** —— 不管在哪个页面、在聊什么，它都在那儿。不用进设置、不用敲命令。
- **可拖动** —— 拖到顺手的地方，位置记住；也可以钉死、缩成纯图标、或贴到右边缘。
- **看得见在干活** —— 清理时按钮亮红光，面板外框有小火箭绕一圈走完 4 段（每段 25%），正在清的那一行有陨石飞过。
- **关了也不中断** —— 点掉面板它会继续在后台清，清完自动弹出来告诉你结果，按钮转绿并闪 5 下。
- **不会删错东西** —— 所有可删路径由 host 拼出，浏览器只能传目标 id，删前逐条白名单校验。

## 功能

### 按钮形态（右键菜单切换，或 设置 → 缓存清理）

| 形态 | 说明 |
| --- | --- |
| 浮动按钮 | 可拖到任意位置，带文字，位置自动记住 |
| 纯图标 | 36px 圆图标，也能拖，最省地方 |
| 固定在右上角 | 钉住不动，避免误拖 |
| 贴右边缘 | 右侧竖向标签，不挡内容 |

**右键菜单**：切换形态 / 立即统计并清理 / 设置 / 隐藏

**隐藏**：右键隐藏后直到下次打开 DSH 才回来（标记存 `sessionStorage`）。想立刻叫回来：设置 → 缓存清理 → 显示。

### 清理动画

- **按钮氛围灯**：清理中红光呼吸；完成后转绿光并**闪 5 下**提醒
- **行内陨石**：正在清理的那一行有陨石从左向右飞过，带拖尾
- **外框火箭**：小火箭从面板左上角出发，沿「下 → 右 → 上 → 左」绕一圈，每段代表 25%，带火焰
- **外框进度环**：走过的部分亮起，一眼看出总进度
- **面板弹出**：从按钮位置「蹦」出来（transform-origin 按按钮实时计算），收回时有反向动画

### 后台清理

清理任务活在模块级状态里，**不属于面板组件**。所以：

- 点面板外面 → 面板关闭，清理继续
- 清完自动把面板弹出来显示结果
- 按钮从红转绿、闪 5 下，即使面板一直关着也会提醒

### 面板

- 只列**真的有内容**的目标；0 字节的项默认隐藏（下次长出来会自动出现）
- 默认不自动展开，点一下才开，不占地方
- 半透明毛玻璃，默认 82% 不透明，设置里 35%–100% 可调
- 全选 / 全不选 / 重新统计 / 关闭

## 清理范围

默认勾选（可安全重建）：

| 分组 | 目标 | 说明 |
| --- | --- | --- |
| DSH 自身 | DSH 搜索缓存 | 索引缓存，删后自动重建 |
| DSH 自身 | DSH 图片缩略缓存 | 缩略图，重新打开图片会重建 |
| DSH 自身 | DSH 溢出日志 | 命令输出落盘的临时日志 |
| 开发工具 | uv 包缓存 | Python 依赖缓存，通常几个 GB |
| 开发工具 | npm 缓存 | 下载缓存 |
| 开发工具 | pnpm 存储 | 全局包内容存储 |
| 开发工具 | pip 缓存 | wheel 缓存 |

默认不勾选（会影响下次安装速度，或属于别的软件）：

- **临时文件（7 天前）** —— 系统临时目录里超过 7 天没动过的东西
- **其他软件残留安装包** —— 各 Electron 软件更新器留下的 `installer.exe`，常年几百 MB

**绝不删除**：`$DSH_HOME/cache/attachments/request-images`（旧对话里的图片）、会话、凭证、笔记、设置、插件本体。

## 速度

0.4.0 相对 0.3.0 做了两处优化，实测（24000 文件 / 188MB 合成目录树）：

| 操作 | 0.3.0 | 0.4.0 | 提升 |
| --- | --- | --- | --- |
| 扫描 | 2030ms | 1043ms | **1.7×** |
| 清理 | 17174ms | 12319ms | **1.4×** |

- **扫描**：目录项/子目录全并发（32 路），目标之间也并行；之前是纯串行 `await`，时间基本花在等 syscall 返回。
- **清理**：不再「逐条 measure 再删」（那等于遍历两遍树），改成删除前后各量一次 root 用差值算释放量；删除本身 8 路并发。

## 安全机制

- 可删路径全部由 host 用已知位置拼出，浏览器只能传「目标 id」，永远传不了路径 —— 这个接口不可能是任意文件删除器
- 每个目标声明自己的 roots，删除前逐条再走一次 `inside()` 白名单校验
- 只删 roots 里的内容，**不删 roots 目录本身**
- 删不动的、被占用的文件跳过并计数，不中断
- Origin/Referer 校验；配置入参全部清洗（非法形态回落默认、坐标夹 ±20000、不透明度夹 0.35–1、`disabled` 只认已知目标 id）

## 安装

```sh
# 在 DSH profile 目录里
pnpm add link:<本目录绝对路径>
```

再把 `dsh-cleaner` 加进 profile `package.json` 的 `dsh.profile.bundles`，重启 DSH。

**改完 host 半边必须完全退出 DSH 再打开**；client 半边刷新页面即可。

## 配置

存于 `$DSH_HOME/dsh-cleaner/config.json`，也可在 **设置 → 缓存清理** 里改：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `mode` | `float` | `float` / `icon` / `fixed` / `rail` |
| `x`, `y` | `null` | 浮动位置，`null` = 默认右上角 |
| `opacity` | `0.82` | 面板不透明度，0.35–1 |
| `showEmpty` | `false` | 是否列出 0 字节的项 |
| `autoExpand` | `false` | 是否自动展开面板 |
| `disabled` | `[]` | 关掉的清理目标 id |

## HTTP 接口

- `GET/POST/DELETE /dsh-cleaner/config` —— 偏好读写与重置
- `GET /dsh-cleaner/targets` —— 目标列表 + 磁盘可用（不返回绝对路径）
- `GET /dsh-cleaner/scan[?force=1]` —— 各项大小（60 秒缓存）
- `POST /dsh-cleaner/clean-item?id=<id>` —— 清一项（面板逐项动画的数据源）
- `POST /dsh-cleaner/clean[?id=a&id=b]` —— 批量清理

## 测试

```sh
node test/client.test.mjs   # 61 项
node test/host.test.mjs     # 60 项
node test/e2e.mjs           # 21 项（需 DSH 在 7651/13808 运行）
```

`test/e2e.mjs` 用 CDP 拦截浏览器里 client 的 `/dsh-cleaner/*` 请求，转发到「磁盘上最新代码起的 host」，
不重启 DSH 也能跑完整链路 —— 真实 React 渲染、真实鼠标拖动/右键、真实清理与后台任务。
